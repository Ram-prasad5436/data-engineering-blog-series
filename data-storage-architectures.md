# Data Storage Architectures: Data Warehouse vs. Data Lake vs. Lakehouse

## Overview

This repository contains a technical blog exploring modern data storage architectures and their applications in data engineering.

The article explains how Data Warehouses, Data Lakes, and Lakehouses differ, with a focus on Databricks and its Lakehouse platform.

## Topics Covered

- Data Warehouse architecture
- Data Lake architecture
- Lakehouse architecture
- Databricks and Delta Lake
- Unity Catalog: Catalogs, Schemas, Tables, and Volumes
- Managed and external tables
- Physical data storage
- Medallion Architecture: Bronze, Silver, and Gold
- E-commerce use case for transforming raw data into business insights

## Architecture

The article discusses how data flows through the Bronze, Silver, and Gold layers:

- **Bronze:** Raw ingested data
- **Silver:** Cleaned, validated, and standardized data
- **Gold:** Business-ready data for reporting and analytics
