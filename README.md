## Project 1: Retail Sales Analytics Using Databricks

### Project Overview
This project analyzes retail sales data using Databricks SQL, Unity Catalog, Databricks Genie, and AI/BI Dashboards to transform raw data into meaningful business insights.

### Objectives
- Organize retail sales data using Unity Catalog.
- Analyze overall sales performance using SQL.
- Identify the top five products by revenue.
- Compare sales performance across regions.
- Analyze monthly sales trends.
- Calculate product category revenue contributions.
- Explore business questions using Databricks Genie.
- Build an interactive AI/BI dashboard.

### Tools and Technologies
- Databricks
- Unity Catalog
- Databricks SQL
- Databricks Genie
- AI/BI Dashboards

### Key Results
- **Total Sales Revenue:** $5,019,265.23
- **Total Quantity Sold:** 25,355
- **Total Sales Records:** 1,000
- **Distinct Products:** 100

### SQL Analysis
The project includes five SQL analyses:
1. Overall sales performance.
2. Top five products by sales revenue.
3. Sales performance by region.
4. Monthly sales trends.
5. Sales contribution by product category.

### Dashboard
An interactive dashboard presents key performance indicators, regional sales, top-performing products, monthly trends, and product category performance.
